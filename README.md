# Valentin_Antonin_Mblock_Oskour

## 2 mode (manuel et auto) (changer le mode en appuyer sur Espace)

### Mode Manuel

Utilisation des fléches directionnels pour déplacer le robot et utilisation de la touche B pour changer ça vitesse (altérne entre 50, 100 et 250 de vitesse)

### Mode Auto

Cartographie une zone en avançant et si obstacle en face alors tourne a gauche.
